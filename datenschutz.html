2. Welche Daten verarbeitet die App?

Deine Einträge werden ausschließlich im lokalen Speicher der App auf deinem Gerät abgelegt. Sie werden nicht an den Entwickler oder an Dritte übertragen. Wenn du die App löschst, werden auch diese Daten gelöscht.

Eine Sicherungsdatei oder einen Kalender-Export erstellst du nur selbst. Wohin du diese Datei weitergibst (z. B. Dateien-App, Kalender), entscheidest du.

3. Abruf der Schulferien

Um die Schulferien deines Bundeslandes anzuzeigen, ruft die App öffentliche Ferientermine ab von openholidaysapi.org und ersatzweise von ferien-api.de. Dabei wird nur das Bundesland und das Jahr abgefragt. Wie bei jedem Internetabruf erhält der jeweilige Server technisch bedingt deine IP-Adresse. Es werden keine Schichtdaten übertragen. Die Feiertage berechnet die App selbst, ohne Internet.

4. Web-Version

Die Web-Version wird über GitHub Pages (GitHub Inc.) bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Zugriffsdaten (z. B. IP-Adresse) zur Auslieferung der Seite. Details: Datenschutzerklärung von GitHub.

5. Deine Rechte

Da der Entwickler keine personenbezogenen Daten von dir speichert, kann er dazu auch keine Auskunft geben. Deine Daten auf dem Gerät kannst du jederzeit in der App löschen („Plan“ → „Alle Schichten löschen“) oder indem du die App entfernst. Bei Fragen erreichst du den Verantwortlichen unter der oben genannten E-Mail-Adresse. Du hast außerdem das Recht, dich bei einer Datenschutz-Aufsichtsbehörde zu beschweren.
